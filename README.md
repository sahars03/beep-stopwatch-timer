# BeepST

This is a web application for a simple stopwatch/timer. It also includes the options of beeps at regular intervals, which can be useful during activities such as working out. In Timer mode, there is a ring once the timer has finished.

It has been built using Next.js, specifically React/Tailwind.

## Features

- Simple interface for inputting and displaying time.
- Optional beeps at regular intervals and a ring when the timer is finished.
- Progress bar for showing the progress until the next beep.

## Requirements

- Node.js >= 22.11
- npm >= 11.12
- Next.js >= 16.2.1
- React >= 19.2.4
- Tailwind CSS >= 4.2.2

## Installation

#### 1. clone the repository

```bash
git clone https://github.com/sahars03/beep-stopwatch-timer.git
cd beep-stopwatch-timer
```
#### 2. install dependencies

```bash
npm install
```

#### 3. run the server

```bash
npm run dev
```

#### 4. open the link `http://localhost:3000` to use the application
